# Changelog

## Android 0.3.0

- Backups: save them by hand, compare one with the BMS and restore chosen values, also from another pack of the same model
- Delete, note, export and import backups; the last 50 per pack are kept
- No automatic backup before writing anymore: every review shows the last backup and offers to back up now
- Model and firmware in the pack list and on the overview
- Dashboard with model, lowest and highest cell with their numbers
- New app icon

## Mac 0.1.3

- Backups: save them by hand, compare one with the BMS and restore chosen values, also from another pack of the same model
- Delete, note and import backups, show their files in Finder; the last 50 per pack are kept
- No automatic backup before writing anymore: every review shows the last backup and offers to back up now
- The iPhone and Android versions get the same with their next release

## Mac 0.1.2

- Dashboard and cells on one overview page per pack, with tabs for overview, parameters and switches
- Lowest and highest cell with their numbers, model and firmware on the overview page
- Model and firmware in the sidebar and on the "All Batteries" cards
- New app icon

## Android 0.2.2

First public version.

- Live values, cell view, parameters and switches
- Protected change mode with checks, backup and read-back
- Compare and sync several packs
- Named alarm messages, two warnings verified on a device so far
- Demo mode to try the app without a battery
- Lost connections shown on every pack page and on the overview
- Privacy policy inside the app
- Safety notice before the first change mode
- German and English
